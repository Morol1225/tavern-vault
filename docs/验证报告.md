日期：2026-10-23（北京时间）。原生扩展、标题文件命名、标签筛选及确认编辑的本地验证；未接入用户实际酒馆。

## 本次范围

保留指定电脑文件夹、分类、原文与 HTML、来源信息、搜索、标签筛选、确认编辑和阅读区展开。新增原文、显示副本与 HTML 页面按收藏标题命名，整理确认新标题后同步改名。新建或确认修改内容/标题的单条记录采用 schema 3，兼容读取旧 schema 1、2。根配置不变，旧收藏不自动改名；内容集完整写入后才提交，随后清理旧内容和旧名称。

安装产物是根目录 `manifest.json` 和独立 ES 模块 `index.js`，公开仓库可以直接交给酒馆扩展安装器。代码不依赖助手或远程加载器。原生接口依据官方 1.19.0 源码，详见 `native-extension.md`；用户实际版本未知。

## v0.3.1 扩展设置入口竖排修复

用户提供真实酒馆截图，入口文字逐字换行。官方 1.19.0 的 [通用按钮样式](https://github.com/SillyTavern/SillyTavern/blob/06bde939fb1e9c4c8d8641d810f0a916b5bce127/public/style.css#L3826-L3841) 对 menu_button 使用 min-content 宽度，而此前入口只有该类名，没有自己的宽度和换行约束。

在预览中加入同样的关键宿主样式后，修复前实际测得按钮宽 26px、高 209.5px、文字 8 行，复现用户表现。修复仅为自有入口容器指定横向布局，并为按钮设定自动宽度、按文字撑开及不换行；未修改宿主的全局样式。

修复后同一检查测得约 121.66×33.19px、文字 1 行；点击可打开储藏库。320/390px 同样单行。34 项数据检查和 19 组浏览器检查通过，清单与构建检查通过；新增合成截图 settings-entry.png。用户原截图未纳入仓库。

用户截图是实际故障证据，不代表修复后已在其酒馆通过。实际安装版本、主题样式和更新后显示仍待用户原环境复验。

## v0.3.2 展开正文阅读区

用户要求点击展开后，内容应占满右侧区域。原实现仅移走左侧两列，标题、来源、标签、页面选择和底部说明仍占据正文高度。本地复现中，右侧正文在常规与旧展开模式下均只有约 482.53px 高，而阅读区为 755.16px 高。

新展开模式保留桌面分类与列表，收起右侧阅读区的辅助栏，提供右上角悬浮还原按钮。相同窗口下，正文和 iframe 变为约 873.39×755.16px，与右侧阅读区边界一致；正文高度增加约 272.63px。390px 与 320px 窄窗中，iframe 分别为 390×747px、320×747px，同样占满阅读区。

已检查展开、浮动按钮还原、HTML iframe 内按 Escape 还原、正文按钮状态保持，以及收藏文件没有变化。通过 34 项数据检查、20 组浏览器检查和清单验证。合成截图为 library-expanded.png 和 library-expanded-320.png；用户的原始截图与收藏内容没有纳入仓库。

这些结果来自本地合成宿主与实际构建模块。用户的原酒馆仍需更新至 v0.3.2 并刷新后复验。

## v0.4.0 按收藏标题命名本地文件
