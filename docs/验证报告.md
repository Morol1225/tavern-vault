# 储藏库 v0.3.0 · 验证报告

日期：2026-10-23（北京时间）。原生扩展、标签筛选及确认编辑的本地验证；未接入用户实际酒馆。

## 本次范围

保留指定电脑文件夹、分类、原文与 HTML、来源信息、搜索和整理；承载方式改为酒馆原生扩展，增加先提取指定标签、再排除指定标签的收藏栏预览。旧收藏和库配置继续读取。编辑提交的单条记录采用 schema 2，按 entry.json 指向完整写入的新内容集；原内容随后清理，未编辑记录不迁移。

安装产物是根目录 `manifest.json` 和独立 ES 模块 `index.js`，公开仓库可以直接交给酒馆扩展安装器。代码不依赖助手或远程加载器。原生接口依据官方 1.19.0 源码，详见 `native-extension.md`；用户实际版本未知。

- 没有酒馆助手全局对象也能启动；禁用后移除界面、楼层按钮、设置入口和事件，再启用不重复。
- 无文件夹时保留草稿，新建/复用分类、跨聊天、来源和搜索正确。
- HTML 按钮运行；无法直接读取宿主 DOM；原文作为文字显示，标题不注入管理界面。
- 重载恢复同一模拟库，多 HTML 页切换、关闭重开和来源详情正确。
- 先提取 content，再排除 image：缺失标签不写入、预览正确、自动标题更新、HTML 自身交互运行、原文/页面/快照/记录均无排除标记残留。
- 390px 与 320px 管理界面没有横向溢出，筛选栏可用，保存按钮在可见区域，返回和 Escape 操作通过。
- 列表、标题、原文和 HTML 正文的真实双击均进入编辑；页面按钮的双击保持自身行为。
- 编辑输入、换行、失焦、Escape、取消均不改变模拟目录文件，重开仍是原内容。
- 确认后原文和 HTML 按钮更新，旧内容删除，来源/原收藏时间保留；重载后恢复修改。
- 外来消息不触发编辑；写入失败保留草稿，清理失败单独提示并可重试。
- 测试序列没有未处理页面脚本异常。
