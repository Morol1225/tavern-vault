# 储藏库 v0.1.0

把 SillyTavern 中喜欢的聊天楼层保存到你选定的电脑文件夹，在酒馆内分类、搜索和重读。收藏会保留原文、显示快照、可提取的 HTML 页面，以及“哪个聊天的哪一楼”的来源。

## 安装与第一次使用

1. 使用电脑 Chrome 或 Edge 打开已安装酒馆助手的 SillyTavern。酒馆地址应为浏览器允许的安全环境，例如 `http://localhost:8000`、本机回环地址或 HTTPS。
2. 在酒馆助手的**全局脚本库**中导入 `dist/tavern-vault.json`，启用“储藏库”。不同助手版本的菜单文字可能不同。此文件导入助手脚本库，不是酒馆原生扩展安装器。
3. 点击右下角“储藏库”，或助手提供的同名脚本按钮。点击“选择收藏文件夹”，在浏览器的选择框中选一个新建空文件夹，允许读写。连接已有库时，请选择包含 `tavern-vault.json` 和 `items` 的那一层文件夹。
4. 点击聊天楼层旁的“☆ 收藏”。在收藏栏中填写标题，选择已有分类，或点“新建分类”填写名称，再点“保存到文件夹”。保存前会显示聊天名、楼层号、发言者和当前消息版本。
5. 在储藏库左侧选择分类，中间搜索或选择收藏，右侧切换“页面”“原文”“来源详情”。“整理”可修改标题和分类。展开阅读区能给页面更多空间。

暂未显示的旧楼层也可以收藏：点储藏库上方的“收藏楼层”，填写酒馆显示的实际楼层编号。编号与酒馆一致，不需要加一。

刷新页面后，浏览器会尝试恢复已记住的目录入口。需要时点“重新授权”；浏览器无法记住入口时，重新选择同一收藏文件夹即可。选择文件夹之前不会把收藏正文悄悄保存到浏览器缓存。

## 保存了什么

- 每条收藏保留当前选中的消息版本。切换消息版本后可另存；完全相同的内容与来源会打开已有收藏，避免重复。
- 原文写入 `original.txt`，保留代码、宏、换行和 HTML 文本。
- `rendered.html` 保存当时可取得的显示内容；`pages/page-1.html` 等保存可独立提取的 HTML 页面。
- 收藏仅复制内容，不重新运行楼层宏。尚未显示的旧楼层会保留原文和可提取的 HTML；如果它的外观完全来自酒馆正则或正在运行的页面，请先在聊天中显示此楼层，再收藏显示快照。
- `entry.json` 保存标题、分类编号、来源和原文校验值。分类记录位于根目录 `tavern-vault.json`。
- 收藏是独立副本。原聊天被改写、删楼或删除，不会改动已保存的内容和来源信息。
- 文件夹属于**运行浏览器的这台电脑**。即使酒馆部署在云服务器，收藏也写到你浏览器选中的本地文件夹。

```text
你选择的收藏文件夹/
  tavern-vault.json
  items/
    <稳定的收藏编号>/
      entry.json
      original.txt
      rendered.html
      pages/
        page-1.html
```

备份时复制整个文件夹。请保留根配置和 `entry.json`，仅复制 HTML 页面无法保留分类、来源等信息。初版通过插件管理库内文件，手动改变原文会被校验发现并略过该条。

## HTML 页面可以做什么

收藏内的 HTML/CSS/JavaScript 源码会保留。页面在隔离的阅读容器中打开，自身的按钮、折叠、文本切换和动画可重新执行。多页面楼层有页面选择器。

依赖酒馆的实时变量、MVU、发消息、AI 生成、跨楼通信、父窗口访问或登录的功能，不会自动获得原聊天环境。远程图片、字体、脚本和接口仍依赖原资源可用，并没有批量下载为离线资源。复制 HTML 也不能完整保留已经运行的内存状态、canvas 和通过脚本动态绑定的全部状态。

预览会重新运行页面自身脚本，原文查看只显示文本。没有向收藏页提供目录句柄、连接设置或酒馆写入接口。外部资源请求仍可能按原页面代码发生。

## 常见情况

| 现象 | 处理方法 |
|---|---|
| 找不到储藏库入口 | 检查脚本导入的是助手全局脚本库，并已启用；检查助手是否提供楼层读取接口 |
| 提示环境不支持文件夹读写 | 用电脑 Chrome/Edge，通过 localhost、本机回环地址或 HTTPS 打开酒馆；普通远程 HTTP 地址可能不提供此能力 |
| 需要重新授权 | 点击“重新授权”；未获授权时不继续保存，收藏草稿保留在当前收藏栏 |
| 选了错误的新目录 | 原目录保持不变；在管理界面点击“换个文件夹”选择原来的库 |
| 保存失败 | 查看错误；空间或权限恢复后重试。只有写入并重新核对后才显示成功 |
| 部分收藏被略过 | 底栏显示数量；悬停可看记录编号与原因。原文被外部修改、损坏索引和未完成写入均会报告，插件不会自动删除它们 |
| 分类配置损坏 | 停止写入并保留原文件；请从完整备份恢复或选择新库，不要直接删掉配置文件 |
| 页面打不开或某个按钮无效 | 切到原文检查；页面可能依赖原酒馆或远程资源。可切换“楼层显示快照”，或提供最小页面样本进一步核实 |

初版没有删除收藏或云同步功能。默认不自动捕获聊天，只在你点击收藏时读取指定楼层；不修改原聊天，也不调用 AI。

## 本地构建与检查

需要 Node.js 22 或更高版本，无运行依赖：

```powershell
npm run build
npm test
npm run preview
```

`build` 从 `src/` 生成独立脚本和导入 JSON，并在 `dist/build-manifest.json` 记录源码/产物摘要。源码不含动态远程加载器；Node.js 只用于维护构建，使用者导入 JSON 后不需要运行 Node。

预览命令会输出仅监听本机回环地址的 URL。`preview/` 中使用合成聊天和内存文件夹，运行的是实际构建脚本，不会接入真实聊天或写电脑收藏目录。它只支持界面检查，不能代替真实酒馆的导入、目录授权和持久化验收。

## 当前验证边界

接口依据来自用户提供的类型声明快照，实际 SillyTavern/酒馆助手版本尚未取得。格式和自动检查可在本地完成；真实酒馆的导入、全局脚本生命周期、楼层按钮、文件夹授权、刷新后再次读取仍待目标环境验证。详见 `docs/验证报告.md`。
